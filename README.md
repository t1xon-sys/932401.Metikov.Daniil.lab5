## Цель работы
Научиться манипулировать DOM-деревом: находить элементы, изменять их содержимое, атрибуты и классы, добавлять и удалять элементы, а также сохранять состояние страницы между перезагрузками с помощью `localStorage`.

## Запуск
Открыть `index.html` в браузере. Сообщения о работе скрипта выводятся в консоль (F12 → Console).

## Реализованный функционал


### 1. Поиск элементов

| Метод | Где используется |
|---|---|
| `document.querySelector(".projects-list")` | поиск контейнера со списком проектов |
| `document.getElementById(...)` | поиск кнопок `#add-project-btn`, `#remove-project-btn`, `#toggle-projects-btn`, `#theme-toggle` |
| `container.querySelectorAll(".project-card")` | получение всех карточек проектов (удаление, сохранение) |

### 2. Кнопка «Добавить проект»

1. С помощью `prompt` запрашиваются название и описание проекта.
2. Через `document.createElement` создаётся карточка `<article class="project-card">`. Внутри неё создаются заголовок `<h4>`, описание `<p class="stack">` и кнопка `<button class="btn">Подробнее</button>`.
3. Текст заполняется через `textContent`, классы задаются через `classList.add` / `className`, атрибуты через `setAttribute`.
4. Карточка добавляется в контейнер методом `appendChild`.
5. Обновлённый список сохраняется в `localStorage`.

Если пользователь нажал «Отмена» или ввёл пустое название, карточка не создаётся.


### 3. Кнопка «Удалить последний»

1. Через `querySelectorAll(".project-card")` получается список карточек.
2. Если список не пуст, последняя карточка удаляется методом `remove()`, после чего список сохраняется в `localStorage`.
3. Если карточек нет, в консоль выводится `Нет проектов для удаления` и показывается `alert("Список пуст")`.

### 4. Переключение темы

Кнопка в меню переключает у `<body>` классы `theme-light` и `theme-dark`. В `style.css` для `body.theme-dark` переопределены CSS-переменные (`--color-bg`, `--color-main`, `--color-accent`, `--color-card-bg`, `--color-text` и др.), поэтому меняется оформление всей страницы.

Также меняются текст кнопки («☀️ Светлая тема» / «🌙 Тёмная тема») и атрибут `aria-pressed`. По умолчанию включена **тёмная тема**. Выбранная тема сохраняется в `localStorage`.


### 5. Скрытие и показ блока


Кнопка «Свернуть проекты» добавляет контейнеру списка класс `hidden` (`display: none`), повторное нажатие убирает его (`classList.toggle`). Текст кнопки меняется на «Развернуть проекты» и обратно, атрибут `aria-expanded` обновляется. Состояние сохраняется в `localStorage`.
 
 ### 6. Обработка ошибок

 Проверяется, что контейнер и все кнопки существуют (`if (!element)`). Если какой-то элемент не найден, в консоль выводится сообщение через `console.error` с указанием этого элемента, и выполнение скрипта прекращается (`return`).

 Чтение и запись `localStorage` обёрнуты в `try...catch`. Это защищает от повреждённых данных и от недоступного хранилища.

 ### 7. Кнопка «Подробнее»

 Обработчик назначен на контейнер (делегирование событий через `event.target.closest(".btn")`). Поэтому кнопка работает и у карточек, добавленных динамически. По нажатию показывается `alert` с названием и описанием проекта.
